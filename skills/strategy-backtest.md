# Skill: 策略回测

## 触发条件

用户要求回测某个策略、验证交易思路时使用。

## 标准流程

### 1. 确认策略参数

向用户确认：
- 标的（symbol）
- 时间范围（默认 1 年）
- 策略类型和参数

### 2. 获取数据

```
market_kline → 获取历史K线（建议至少 120 根 bar）
```

### 3. 生成信号

根据策略规则，对每根 bar 生成 buy/sell/hold 信号。

常见策略模板：
- **双均线交叉**：短期 MA 上穿长期 MA → buy，下穿 → sell
- **RSI 超卖超买**：RSI < 30 → buy，RSI > 70 → sell
- **布林带回归**：触及下轨 → buy，触及上轨 → sell
- **MACD 金死叉**：DIF 上穿 DEA → buy，下穿 → sell

### 4. 执行回测

```
run_backtest → 传入 bars + signals + 资金 + 手续费
```

### 5. 分析结果

重点关注：
- 年化收益 vs 基准（买入持有）
- 最大回撤（> 20% 需警示）
- 夏普比率（< 1 说明风险收益比不佳）
- 胜率 + 盈亏比（胜率低但盈亏比高也可接受）
- 交易次数（太少不具统计意义，建议 > 20 次）

### 6. 优化建议

- 如果最大回撤过大 → 建议加止损
- 如果胜率低但盈亏比合理 → 趋势跟踪策略特征，正常
- 如果夏普 < 0.5 → 策略可能无效，建议换参数或换标的
