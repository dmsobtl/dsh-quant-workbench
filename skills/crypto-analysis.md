# Skill: 加密货币分析

## 触发条件

用户询问加密货币行情、分析 BTC/ETH/山寨币时使用。

## 分析框架

### 1. 快速概览

```
market_quote BTC → 当前价格和 24h 变动
market_quote ETH → ETH 联动情况
```

### 2. 技术面

```
market_kline → 日线 60 根
calc_indicator RSI → 超买超卖判断
calc_indicator bollinger → 波动区间
calc_indicator macd → 趋势判断
```

### 3. 多周期确认

- 周线看大趋势
- 日线看中期方向
- 4h 线看短期入场点

### 4. 关键价位

- 前高/前低
- 整数关口（BTC: 每 5000 一档，ETH: 每 500 一档）
- 布林带上下轨

## 加密货币特殊注意

- 24/7 交易，无涨跌停
- 波动率远高于传统市场
- 流动性可能集中在特定时段（美盘时段）
- 山寨币高度相关 BTC，先看 BTC 再看个币
- 资金费率和合约持仓量（本插件暂不支持，需提示用户）

## 输出模板

```
## BTC 技术分析 (2026-08-14)

当前价格：$XX,XXX（24h +X.X%）
趋势判断：[多头/空头/震荡]

关键指标：
- RSI(14)：XX（[超买/中性/超卖]）
- MACD：[金叉/死叉/零轴上方/下方]
- 布林带：价格位于 [上/中/下] 轨附近

支撑/阻力：
- 上方阻力：$XX,XXX
- 下方支撑：$XX,XXX

短期展望：...
风险提示：加密货币波动极大，以上为技术面分析，不构成投资建议。
```
